[Claude specific rules](https://code.claude.com/docs/en/memory#organize-rules-with-claude/rules/) are defined in markdown files with YAML front matter that specifies the `paths` (glob patterns) to which the rules apply.  These files can be organized in a directory structure that reflects different teams, languages, or modules.  For example, you might have a `frontend.instructions.md` file that applies to all frontend-related files, and a `backend.instructions.md` file for backend-related files.  The rules defined in these files will be automatically applied to the specified paths, allowing you to enforce consistent behaviors across your codebase.
